# Центр имплантации «Подмосковье»

Предварительная версия лендинга для согласования дизайна и содержания.

Статическая страница: `index.html`. Изображения и шрифты хранятся локально в `assets`.

Формы демонстрационные: введённые данные не отправляются. Страница закрыта от индексации метатегом `noindex,nofollow`.

Иллюстрации служат для визуального объяснения лечения. Подключение заявок выполняется отдельно перед запуском рабочего сайта.
