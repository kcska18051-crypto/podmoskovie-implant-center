# Подключение актуальных стилей

Подключите только styles.css вместо base.css, fonts.css, design.css, revision.css, reference-audit.css и footer.css:

```html
<link rel="stylesheet" href="styles.css?v=unified17">
```

Не подключайте старые файлы одновременно с новым. Папка assets должна находиться рядом со styles.css; при другом размещении поправьте относительные пути url() к шрифтам и изображениям.

Основная мобильная граница — 800 px включительно; десктоп — от 801 px. Уточнения для узких телефонов сохранены. Порядок каскада соответствует текущему согласованному макету.
