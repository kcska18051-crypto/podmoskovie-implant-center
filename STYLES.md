# Стили страницы «Центр имплантации»

Актуальная версия: ветка main, файл styles.css. Это очищенный источник, а не склейка старых файлов. Все дальнейшие изменения вносить в него; не добавлять файлы с правками поверх.

## Перенос

1. Взять index.html, styles.css, app.js и assets из одного коммита main.
2. Удалить прежние подключения base.css, fonts.css, design.css, revision.css, reference-audit.css, footer.css. Удалить перенесённые ранее копии правил этих блоков из CSS основного сайта.
3. Подключить один файл:

```html
<link rel="stylesheet" href="styles.css?v=prices25">
```

4. Сохранить assets рядом с CSS либо скорректировать относительные url().
5. Очистить кеш сайта/CDN. При следующих правках менять версию в href.

Мобильные правила действуют до 800 px включительно, десктоп — от 801 px; более узкие настройки телефонов сохранены.

Повтор селектора в разных media-запросах, :hover/:focus и состояниях вкладок необходим для адаптивности и интерактивности. Повторные объявления одного свойства того же селектора в одинаковых условиях удалены. Стили удалённых старых блоков также удалены.

Не смешивать CSS из разных веток и коммитов. styles.css содержит глобальные правила страницы (body, заголовки, кнопки); при встраивании в существующий шаблон нужно также проверить его собственные глобальные стили. Чужой шаблон не входил в проверку.
